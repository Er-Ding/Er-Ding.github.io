# Academic Notes 本地可编辑版本

此目录用于在本地修改现有个人主页，或交给 Claude 继续编辑。

## 导出范围与来源

- 来源：https://academic-notes.stephenzhu17.chatgpt.site/
- 整理日期：2026-10-10（北京时间）。
- 页面文字、结构、样式和图标来自当日公开部署版本，保留了当前占位内容。
- 线上版本使用 React / Vinext；当前会话没有原始源码仓库的访问接口，管理页面也没有找到源码下载选项。
- 这个目录是从部署页面整理的静态迁移版。筛选功能改为独立的原生 JavaScript，移除了框架运行时和托管平台注入脚本。
- 尚未取得原始 React / TypeScript 工程、构建配置或 Git 历史。本目录不包含服务端代码、数据库或部署凭据。

## 修改哪些文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 姓名、个人简介、研究方向、论文项目、个人经历、邮箱和链接 |
| `styles.css` | 配色、字体、间距、布局、动画和移动端样式 |
| `script.js` | “全部 / 论文 / 项目”筛选逻辑 |
| `favicon.svg` | 浏览器标签页图标 |
| `portrait-cutout.png` | 个人信息卡片中的人物照片（已去除白底，透明背景，800×800） |
| `portrait.jpg` | 原始白底证件照（800×800，备用） |

新增论文或项目时，复制一个 `article.work-item`，将 `data-type` 设为 `论文` 或 `项目`，并修改其中的文字和链接。筛选按钮使用对应的 `data-filter`。

当前“CV 待添加”“链接待添加”等内容是占位文字。需要可点击的链接时，将对应的占位 `span` 改成带有 `href` 的 `a` 标签，并保留其样式类。

## 本地打开

可以直接用浏览器打开 `/Volumes/disk2/CV/index.html`，无需安装依赖或构建。

也可以在终端启动一个仅供本机访问的静态服务器：

```sh
cd /Volumes/disk2/CV
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8000/ 。修改文件后刷新浏览器；终端按 `Ctrl+C` 停止服务。

本地修改不会自动同步到现有的 `chatgpt.site` 网址。这个目录可以作为静态网站部署到你选定的托管服务；若要继续更新现有 Sites 域名，需要通过原站点项目的源码写入和发布流程重新部署。

未启动本地服务器或进行浏览器功能检查；未生成测试文件或测试结果文件。
